① 一个片段 = 脚本 → 故事板 → 视频

故事板不再是单独的工序，而是片场里每个片段的中间一步。选中片段后，中间预览顶部的「故事板 | 视频」切换两种画面，右边仍是这段的脚本（提示词）。

② 默认看哪一面

  • 这段还没有视频 → 默认「故事板」，先把宫格图定下来。
  • 已经有视频 → 默认「视频」。
  • 点「生成视频」后自动切到「视频」看进度。

③ 提醒，不拦截

没有故事板、或原稿改过（过期）时，照样能生成视频；右侧参考素材条第一格是故事板芯片，标出「未生成 / 已过期」，可以点 × 本次不带。

④ 改了脚本，故事板马上标过期

在右侧改提示词（试试改【时间轴】），中间宫格图左上角出现「原稿已改 · 重新生成」，片段条上故事板那一格变成琥珀色。

⑤ 片段条一眼看进度

每格底部两段小条：左边故事板、右边视频。绿 = 好了，琥珀 = 过期，闪 = 生成中，红 = 失败。没视频时缩略图显示故事板。

⑥ 整集批量

顶部条「故事板 4/6」显示进度，「补齐故事板 · n」一次补完缺的和过期的；视频的批量生成保持原样。

⑦ 没有分镜脚本

片场空状态只有一个「生成分镜脚本」。分镜好了，故事板和视频都在这里接着做。重新生成分镜脚本会清空片段，旧故事板一起清掉（确认弹窗里写明）。

不在本原型里

  • 故事板的图片模型和提示词在「项目设置」里选（已实现）。
  • 在画布里查看历史版本：预览下方的版本圆点 + 「在画布中打开」。
