# 短剧仿拍出片实施方案

本项接通参考集校订与已有分集片场，完成既定四项方案。采用、写稿、生成和合成分别保存自己的输入依据，后续修改原片拆解不改变已经开始的制作。实现与验收连续推进，只有真实模型效果、耗时和费用需要在配置渠道后另行验收。

2026-11-19，前后端已实现。数据库迁移为 `0049`（采用记录与分集、片段依据）和 `0050`（单镜生成意图），服务启动时按现有迁移机制执行。新增界面沿用原短剧片场及成片页。

## 两种制作方式

- **按原镜重拍**：从已保存的参考修订生成一集跟拍剧本和逐镜片段。人物使用已经对应的新角色，提示词引用项目角色节点，形象与音色由现有素材组装逻辑处理。原片毫秒区间、目标成片时长、模型申请秒数分别保存。采用后直接进入片场，可改提示词、只重做一镜、选版、重排和合成。
- **原创改编**：把所选参考修订、角色对应和改编要求固定到一个未锁定的分集。现有「生成剧本」任务以这份依据写原创剧本，再经审核、资产拆解和分镜进入片场。继续使用已有任务队列、文本模型和计费；不要求原创镜头与原片逐一对应。

## 保存与更新

采用记录固定参考修订、原素材、完整文档、角色到新节点的对应和目标分集。网络重传复用创建键，相同参考修订的默认采用返回已经建立的关联。删除分集后，旧采用记录保留并标明目标已经删除。

更新已有跟拍集必须显式选择原镜范围并携带分集修订。按源镜稳定 ID 更新对应片段，保留这些片段已采用的视频；其他片段、其他集和任务历史不变。新增源镜可以追加，重新采用不自动删除旧镜。正在执行的生成与剧本任务阻止冲突修改。

逐镜生成冻结片段修订、有效提示词、输入素材、模型和原片依据。同一次提交的重传复用同一输入与任务；主动重拍使用新键。失败保留已选视频。模型支持视频参考时，可以使用服务端裁出的无声原镜片段；模型不支持时可选择仅用目标角色和文字生成。

合成固定提交时的镜序、已选素材和裁剪窗口。跟拍片段按目标毫秒时长裁取，普通原创片段保持原有全长行为。裁剪起点或长度变化会使旧成片显示过期。素材不足以覆盖指定窗口时明确失败，不静默缩短成片。

## 界面

参考集校订页增加「采用到片场」，选择跟拍或原创改编；更新已有集时显示将修改的镜头范围。采用记录提供目标分集入口。片场沿用现有布局，在所选片段增加原片回放、目标时长、裁剪起点和无声视频参考选择，生成和选版仍使用现有操作。

## 验收

1. 两个参考集采用同一新角色，重复采用和网络重传不重复建集。
2. 修订参考稿后只更新指定镜头，核对其他镜头、另一集和已选视频。
3. 单镜重传只创建一个任务并冻结一次积分；失败保留旧版，刷新可以恢复。
4. 提交合成后再改选版与窗口，结果仍使用提交时快照；真实 FFmpeg 验证精确时长、镜序和声音。
5. 原创改编的模型输入使用采用时的原片和角色快照，结果经现有流水线进入片场。
6. 前后端定向测试、完整检查与相关竞态测试通过。测试和 Go 编译串行，主代理与子代理合计最多两个。

本地真实 HTTP 验收已通过 28 项检查，使用独立 PostgreSQL、真实登录路由和素材服务。视频模型使用可核对的本地确定性视频，文本模型使用固定合法输出，任务创建、积分冻结与结算、写稿、资产拆解锁集和分镜保存均走正式服务。两集实际视频各为 5.000 秒，第一集红色→紫色、440→约 1320 Hz，第二集蓝色→黄色、660→1100 Hz；静音原镜裁片为 2.500 秒且无音轨。服务记录的 5022 毫秒包含现有 AAC 元数据探测差异，ffprobe 的视频轨及容器时长均为 5.000 秒。

## 接口补充

| 操作 | 契约 |
| --- | --- |
| 采用参考稿 | `POST /dramas/:id/references/:reference/adopt`，`revision`、`request_key`、`mode` 必填；mode 为 `follow` 或 `rewrite`。更新已有跟拍集还须 `target_episode_no`、`episode_revision`、`shot_ids`。原创改编可传 `instruction`。成功返回 200。 |
| 恢复已采用记录 | `GET /dramas/:id/reference-adoptions`，`data` 直接为数组。返回采用的参考修订、实际分集 ID、当前集号、涉及片段以及分集是否删除。 |
| 调整目标窗口 | 原有 `PATCH /drama-segments/:sid` 增加 `target_duration_ms` 和 `trim_start_ms`；须携带 `revision`，只适用于跟拍片段。不会改变原片时码或已选视频。 |
| 单镜生成 | 原有 `POST /drama-segments/:sid/generate` 对跟拍片段要求 `revision` 和 `Idempotency-Key`。`use_reference_video=true` 时由服务器准备无声原镜裁片，替换输入的 `videos`。请求参数改变须使用新键；相同键的重传恢复首次冻结的输入。 |
| 合成单集 | 继续使用 `POST /dramas/:id/jobs` 的 `compose` 步骤。后台固定每个采用素材的毫秒裁剪窗口，视频不足时明确失败。 |

采用记录和生成意图中的原稿、角色对应、素材及模型输入保留用于追溯。重新分析原片、改角色名字或更换当前模型配置，都不会改写已经保存的制作依据。素材图和音色在每次主动生成前重新读取，并随本次生成输入保存。
