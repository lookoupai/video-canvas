## 10. A5 采用与付费生成

生成接口要求当前草稿修订、采用回执、原报价请求和 `plan_digest`。批次先持久保存逐镜稳定业务键及请求，再提交到已有片段生成服务。任务创建沿用片段服务幂等键，任务 ID 随批次回执持久化；响应丢失或部分失败后，重复批次请求恢复已有结果。不同新键的提交会重新核验配置摘要、单镜报价、素材、采用分集及片段当前修订；提示词、素材、时长、裁剪或采用回执变化时返回冲突。Agnes 视频引用在冻结积分前检查实际裁片大小、时长和帧率。

短剧 Agent 新增 `drama_reference_apply` 与 `drama_generate_segments`，均由固定草稿、项目和计划摘要派生稳定审批键，走既有签名审批通道。采用与可计费生成分别要求用户确认；durable 工具按批准回执恢复。只读的 `drama_reference_read(scope=quote)` 供 Agent 获取同一报价计划。关键帧图片沿用 `generate_media` 的生成和积分审批，确认图片生成成功并由用户核验素材后，再作为报价图片输入。
